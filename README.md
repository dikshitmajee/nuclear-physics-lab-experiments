# Nuclear Physics Laboratory Experiments

Author: Dikshit Majee

This repository contains reports and analysis from nuclear physics laboratory experiments performed during my MSc Physics program.

## Experiments Included

### Gamma Ray Spectroscopy
Study of gamma-ray emission using NaI detector and Multichannel Analyzer.

### Detector Calibration
Energy calibration of gamma-ray spectra using known sources.

### Data Analysis
Extraction of energy peaks and interpretation of nuclear transitions.

## Topics Covered

- Radiation detection
- Gamma spectroscopy
- Nuclear decay analysis
- Detector calibration
